https://platformio.org/ based code for JJ timer and it's remote.

Simply download the VSCode extension for platformio and additionally install [pymcuprog](https://docs.platformio.org/en/latest/platforms/atmelmegaavr.html#upload-using-pymcuprog-serialupdi), inside the venv created for platformio (usually activated by `source ~/.platformio/penv/bin/activate`), which is used to upload the code.
